## v03.1 변경 (v03.0 첫 실행 결과: 화면이 하얗게 날아감)

**v03.0에서 하얗게 날아간 원인 추정** [Inference, AE 화면 캡처 1장 기준]
1. **아기 자리 플레이스홀더가 너무 밝았음:** 거의 흰 살색 그라디언트였습니다. Gradient Ramp는 마스크를 무시하고 레이어 전체를 채울 수 있어서, 원형 창 밖까지 밝게 번졌을 가능성이 큽니다.
2. **밝은 레이어를 겹쳐 더했음:** 성운(Screen), 웜 스필(Add), 전경 보케(Add, 35%)가 모두 밝았고, 그 위에 Glow 3단을 낮은 임계값으로 누적했습니다.
3. **선형 합성이 Add 레이어를 더 밝게 만들었음.**
4. Fractal Noise도 마스크를 무시할 수 있어서, 웜 스필과 보케에 건 마스크가 효과가 없었을 수 있습니다.

## 0. v02를 버리는 이유 (한 줄 요약)

v02는 코드로 렌더한 그림을 AE로 옮겨 적은 파일이었습니다. 레이어 143개를 스크립트가 만들었고, 사람이 눈으로 조정한 단계가 없었습니다. v03은 **스크립트는 뼈대만 만들고, 룩은 AE에서 직접 본다**는 원칙으로 갑니다. 버리는 것은 v02의 제작 방식입니다. v02에서 채택된 구성 요소(아기 원형 창, 따뜻한 후광, 하단 빛줄기)는 그대로 유지합니다.

## 1. 지적 사항 → 해결 방식

| 지적 | v02 원인 | v03 해결 |
|---|---|---|
| 아기가 멈춰 있다 | 1.3초 소스 → 나머지 10.7초 프리즈 | `SRC_BABY_PLATE` 교체 슬롯(14초). 속도·시작점은 CTRL 슬라이더로 조절하고, **정지 프레임 금지**. 소스가 짧으면 Timewarp로 슬로모션 처리 |
| 배경이 단조롭다 | 평면 위 도형 반복 | 깊이 4단 분리: 성운(z 3000) / 별(z 1400) / 히어로(z 0) / 전경 보케(z −700). 성운 2겹(쿨·웜)이 계속 흐름 |
| 빛이 싸 보인다 | 8bpc·비선형 합성, 도형 글로우 | 16bpc, 광원은 Saber(링·궤도 2·하단 빛줄기)로 제한, 글로우는 높은 임계값 3단을 약하게 누적(v03.1에서 선형 합성은 OFF) |

| 타이포가 약하다 | 기본 고딕, 페이드만 | 세리프 국문(Noto Serif KR 또는 나눔명조) + 굵기 대비(Light 66 / SemiBold 104) + 넓은 자간 영문 캡션. 글자별 블러 등장 + 자간 정착 + 라이트 스윕 |
| 전체가 PPT 같다 | 요소가 각각 들어오고 멈춤 | 아래 2장의 모션 원칙 적용 |

## 2. PPT 느낌을 없애는 모션 원칙

PPT처럼 보이는 이유는 효과가 적어서가 아닙니다. **모든 요소가 같은 방식으로 따로 들어와서 멈추기 때문**입니다.

1. **화면 전체에 멈추는 순간이 없어야 합니다.** 카메라, 성운, 별, 텍스트 z 드리프트가 12초 내내 움직입니다.
2. **주인공 모션은 하나입니다.** 빛이 링을 그리고, 그 빛이 아기 창을 여는 흐름이 컷 전체의 인과입니다. 나머지 요소는 이 흐름에 반응합니다.
3. **등장 타이밍을 겹칩니다.** 앞 요소가 끝나기 전에 다음 요소가 시작합니다(링 → 궤도 0.8초 뒤, 창 0.9초 뒤, 텍스트 줄 사이 0.55초).
4. **이징을 통일합니다.** 등장은 cubic ease-out(빠르게 나와 길게 정착), 카메라는 ease-in-out입니다. AE 기본 Easy Ease(33%)는 쓰지 않습니다.
5. **긴 정착 구간을 둡니다.** 자간이 4.5초에 걸쳐 천천히 좁혀집니다. 글자가 "도착"하지 않고 계속 자리를 잡는 느낌을 줍니다.

## 5. 실제 촬영본 교체 방법

1. 프로젝트 패널 `01_REPLACE_SOURCE/SRC_BABY_PLATE`를 엽니다.
2. 촬영본을 넣고 `PLACEHOLDER_BG`와 안내 텍스트를 끕니다(삭제해도 됩니다).
3. MAIN의 CTRL에서 `Baby X/Y Offset`, `Baby Scale %`로 얼굴을 원 중앙에 맞춥니다. 원 마스크는 화면에 고정돼 있어 소스만 움직입니다.
4. `Baby Start (s)`로 쓸 구간을 고르고 `Baby Speed %`로 속도를 정합니다.

**촬영본 조건:** 12초 컷에 속도 100%면 12초 이상이 필요합니다. 여유분을 포함하면 14초 이상이어야 합니다. 소스가 짧으면 속도를 60–80%로 낮추고, BABY_PLATE에 Timewarp(Pixel Motion)를 추가합니다. 마지막 프레임에서 정지하는 설정은 금지입니다.

**고르면 좋은 소스:** 정면이나 3/4 각도, 눈을 뜨고 있고 작은 표정 변화(깜빡임, 입 움직임, 손)가 있는 컷. 배경은 어둡거나 단순해야 원형 창 안에서 얼굴이 뜹니다.

## 6. AE에서 반드시 눈으로 확인할 항목

스크립트가 파라미터를 이름이나 순서로 찾아 넣었습니다. AE 언어 설정이나 버전에 따라 값이 들어가지 않을 수 있습니다. 빌드 로그의 `MANUAL`, `VERIFY` 줄이 확인할 목록입니다.

| 항목 | 목표 | 판단 기준 |
|---|---|---|
| Saber Core Type | Layer Masks | 빛이 원 마스크를 따라가는지 |
| Saber Composite Settings | Transparent | 링 레이어가 검은 사각형으로 보이지 않는지 |
| Saber End Offset | 0→100 드로우온 | 광점이 원을 한 바퀴 그리는지(방향이 반대면 Start/End 교환) |
| Saber Glow Intensity | 링 9 / 궤도 3·2 / 빛줄기 3 | 링만 주인공이고 궤도는 보조 수준인지 |
| Glow Threshold | 88 / 84 / 80% | 밝은 부분만 번지고 네이비 배경은 뜨지 않는지 |
| Fractal Noise(성운) | Contrast 115 / Brightness −48 / Scale 900 | 구름처럼 보이고 격자 패턴이 안 보이는지 |
| CC Star Burst | Grid 9·34, Size 22·55 | 별이 규칙적으로 줄지어 보이면 Scatter를 올리기 |
| 폰트 | Noto Serif KR 또는 나눔명조 | 설치돼 있지 않으면 AppleMyungjo로 대체됨 |

**빛 룩의 기준 세 가지:** (1) 순백색을 쓰지 않고 웜 코어와 쿨 림으로 색온도를 분리합니다. (2) 광원은 링 하나가 주인공입니다. (3) 글로우는 넓을수록 약하게 누적합니다. 셋 중 하나라도 어긋나면 다시 싸 보입니다.

## 7. 실행 순서

1. After Effects에서 **새 프로젝트**를 엽니다.
2. 환경 설정 > 스크립팅 및 표현식 > "스크립트가 파일을 작성하고 네트워크에 액세스하도록 허용"을 켭니다.
3. 파일 > 스크립트 > 스크립트 파일 실행 > `BUILD_SC01_v03_2.jsx`(Drive 파일명, 저장소에서는 `BUILD_SC01_v03.jsx`)를 선택합니다.
4. 스크립트와 같은 폴더에 `AHENG_SC01_v03_EDITABLE.aep`와 `BUILD_LOG_SC01_v03_*.txt`가 생깁니다.
5. 로그의 `MANUAL`/`VERIFY` 항목을 6장 표로 확인합니다.
6. 첫 프리뷰는 Half 해상도로 봅니다. 16bpc, DOF, 모션 블러가 켜져 있어 Full 해상도는 무겁습니다.
7. 스크립트는 항상 새 프로젝트를 만듭니다. v03.0 `.aep`는 덮어쓰지 않고, 같은 이름이 있으면 시간값을 붙여 따로 저장합니다.

## 8. 검증 범위 (정직하게)

- **v03.1 오류 원인:** AE 스크립팅 API는 실루엣 알파 모드 이름이 `SILHOUETE_ALPHA`(T 하나)인데 `SILHOUETTE_ALPHA`로 썼습니다. 기존 모의 테스트가 없는 이름도 통과시켜 잡지 못했습니다. v03.2부터는 AE 스크립팅 가이드에 있는 enum 목록만 허용하는 엄격한 모의 테스트(`src/test/mock_strict.cjs`)로 검사합니다. 이 테스트는 v03.1 파일에서 AE와 같은 오류를 재현합니다.
- **확인함:** JSX 문법 검사, ExtendScript(ES3) 비호환 문법 없음, 한글 문자열을 코드값으로 저장(인코딩 문제 없음), 가짜 AE 객체 모델로 스크립트 끝까지 실행(오타·미정의 변수 없음).
- **확인 못 함:** 실제 AE 실행, 렌더 결과, Saber 파라미터 이름과 값 체계, 이펙트 파라미터 인덱스가 AE 26.3에서 맞는지. 이 환경에는 AE가 없습니다.
- 따라서 첫 실행에서 오류가 나면 BUILD_LOG와 오류창 내용을 그대로 보내 주세요.
