## 연출 콘셉트: "작은 빛 하나가 세상이 된다"
스토리보드의 고정 구도를 버리고, 내레이션 세 문장을 **한 번의 연속된 변화**로 보여 줍니다.

| 시간 | 내레이션 | 화면 | 구도 |
|---|---|---|---|
| 0–1.2s | — | 어둠, 별만 | 카메라가 가까이서 시작 |
| 1.2–2.4s | 한 아이가 태어납니다. | 화면 한가운데 **작은 빛 하나**가 두 번 박동(심장 박동 리듬), 가로 렌즈 줄기 | 정중앙, 대칭 |
| 2.4–4.0s | (호흡) | 빛이 부풀며 **원형 창이 빛에서 열림**. 후광이 번지고 링이 그려짐 | 정중앙 |
| 4.0–5.7s | 작은 시작이, 세상을 바꿉니다. | 창이 **오른쪽 1/3로 이동**, 창에서 빛 입자가 바깥으로 퍼짐, 왼쪽에 카피 등장 | 대칭에서 3분할로 |
| 0–5.6s | | 카메라 **풀백**(가까이 → 넓게) = 세상이 넓어짐 | |
| 5.6–12s | | 카메라 아주 느린 푸시인 | |
| 8.2–11.0s | 오늘의 작은 빛이, 우리의 내일을 밝힙니다. | 화면 아래 **빛의 길**이 왼쪽에서 오른쪽으로 그려지고, 길 위의 **작은 별 6개**가 차례로 켜짐 | |
| 11.0–12s | | 카피 퇴장, 빛의 길은 화면 밖 오른쪽으로 → SC02 | |

- **핵심 문장과의 연결:** "작은 빛 → 창(아이) → 퍼지는 빛(세상) → 빛의 길과 작은 별들(내일)". 수정 원고의 핵심 문장 "오늘의 작은 별들이 더 밝은 내일을 만듭니다"와 SC14 별 엔딩을 앞에서 미리 암시합니다.
- **PPT 느낌을 없애는 방법:** 구도가 한 번 크게 바뀌고(중앙 → 3분할), 카메라가 방향을 한 번 바꾸고(풀백 → 푸시인), 모든 등장이 앞 동작에서 이어집니다.

## 기술 변경
- **광원을 AE 기본 셰이프로 교체:** Saber를 쓰지 않습니다. 점광, 링, 궤도, 빛의 길을 셰이프 선과 채우기로 만들고, 가우시안 블러 복제본을 겹쳐 글로우를 냅니다. 파라미터를 추측할 필요가 없어서 결과를 예측할 수 있습니다.
- **HERO_RIG:** 창·후광·링·궤도·입자가 모두 하나의 널에 붙어 함께 움직입니다. 최종 위치는 CTRL `Hero X End`/`Hero Y End`로 정합니다.
- **얼굴 보호:** 창은 스텐실로 원 밖이 잘립니다. 궤도는 창 뒤 평면에 있어서 얼굴 앞으로 지나가지 않습니다. 입자와 보케는 창 위에 구멍을 냅니다. 점광만 2.4–3.6초의 전환 순간에 창 앞에서 사라집니다(빛이 아이가 되는 장면).
- **타이포:** 56 / 90px, 자간 정착은 +14 → 0을 2.4초 동안. 왼쪽 단의 너비를 약 700px로 제한해 창과 150px 이상 떨어뜨림.
- **Glow:** 임계값 72%, 반경 70 한 단만. 광원 자체에 글로우가 있으므로 전체 블룸은 보조입니다(`Bloom %` 40).

## CTRL 슬라이더
- 타이밍: `Point Start` 1.2 / `Bloom Start` 2.4 / `Layout Start` 4.0 / `Text Start` 4.8 / `Path Start` 8.2. 가이드 녹음 후 이 다섯 개만 옮기면 됩니다.
- 룩: `Light %`(모든 글로우), `Halo %` 70, `Sparks %` 70, `Nebula %`, `Bokeh %` 18, `Bloom %` 40
- 카메라: `Camera Pull (px)` 700, `Camera Push End (px)` 90, `Camera Drift`, `DOF Aperture`
- 아기: `Baby Speed %`, `Baby Start`, `Baby Scale %`, `Baby X/Y Offset`

**룩 조정 순서:** 먼저 `Light %`로 전체 빛의 양을 정합니다. 그다음 `Halo %`, 마지막으로 `Bloom %`를 올립니다. 아기 얼굴이 화면에서 가장 밝은 요소로 남는 선에서 멈춥니다.
